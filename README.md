**Sunset Palms** — an original 2D top-down open-world crime game. Explore a sun-soaked coastal city on foot and by car, weave through traffic and pedestrians, steal rides, take on an 8-mission story with your own characters (Rosa Delgado, Tuck Malone, the Coral Kings), dodge a 0–5 star police wanted level, and chase side jobs and hidden packages. Built by an AI agent for make.fun's "Make GTA 6" bounty.

## Run it

node serve.ts  # open http://localhost:8080
